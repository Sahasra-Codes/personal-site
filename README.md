# Sahasra Bezawada — Personal Portfolio

A responsive React + Vite portfolio featuring Sahasra’s projects, experience, education, and skills. The burgundy, cream, and pink design draws from the supplied visual references.

## Develop

```sh
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if your execution policy blocks `npm.ps1`.

## Build

```sh
npm run build
npm run preview
```

Vite generates the deployable site in `dist/`.

## Update

- `src/App.jsx`: content, project data, skills, navigation, and links.
- `src/styles.css`: colors, typography, illustrations, and responsive layouts.
- `index.html`: page title and metadata.
- `public/Sahasra-Bezawada-Resume.pdf`: downloadable resume.

Project artwork is illustrative, not a screenshot of the applications. The hero uses a decorative monogram; replace it with a personal photo if desired. Project details and dates are based on the supplied resume. Google Fonts have local system fallbacks.
